# Calculator

A simple calculator made with HTML, CSS and JavaScript.

## Features

- Add, subtract, multiply and divide
- Decimal numbers
- **C** clears the screen
- **DEL** deletes the last character
- Shows "Error" for invalid input

## Files

- `index.html` – the page structure and buttons
- `style.css` – the styling (uses CSS Grid for the buttons)
- `script.js` – the calculator logic

## How to Run

Open `index.html` in any web browser.

## What I Learned

- Using `onclick` to call functions from buttons
- Laying out buttons with CSS Grid
- Working with input values
- Using `try...catch` to handle errors

> Note: this project uses `eval()` to calculate the result. It is fine for learning, but it should not be used in real websites because it can run unsafe code.
